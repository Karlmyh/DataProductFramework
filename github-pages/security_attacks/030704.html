企业违约预测 API
攻击页面

输入单家企业的信用信息，实时返回未来90天违约概率与风险标签。

攻击面判定

核心交付

接收一家企业的六维信用信息，返回未来90天违约概率。

主要暴露

概率响应将六个输入维度压缩为连续数值，可能被用来反演未公开的近90天逾期率。

分类边界

030704 允许对新企业样本反复调用；030501—030503 只发布既定企业的指数、等级或排名。

当前攻击场景

  1. 60家完整参考企业
  2. 40家隐藏逾期率的目标企业
  3. 对每家企业读取一次 API 违约概率
  4. 学习代理公式并反演逾期率

主要攻击

  1. 01违约概率规则学习
  2. 02近90天逾期率反演
