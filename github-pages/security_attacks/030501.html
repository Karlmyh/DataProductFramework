攻击面 · 030501

数值型指标
攻击页面

在100家模拟企业、6个信用维度上发布0—100的连续信用风险指数。

攻击面判定

核心交付

针对既定企业发布一位小数的信用风险指数，不接受任意新企业特征预测。

主要暴露

连续指数为未知规则学习提供精确信号，可能泄露参与计算但未公开的逾期率。

分类边界

指标针对既定对象和口径预先形成；任意新输入的预测函数归入 0307。

统一模拟数据与真实产品规则

统一数据集

100家模拟企业；资产负债率、现金流紧张度、营收波动度、经营年限风险、司法风险、近90天逾期率，共6维。

敏感维度

近90天逾期率参与产品计算，但不直接向使用者公开。

攻击者知识

60家参考企业六维全知；40家目标企业只知道前五维以及产品发布的风险指数。

真实公式：R = clip[0,100](0.26×资产负债率 + 0.18×现金流紧张度 + 0.14×营收波动度 + 0.10×经营年限风险 + 0.10×司法风险 + 0.70×近90天逾期率)。

该公式只对演示观察者公开，用于核对产品和评估攻击；攻击代码不会读取真实系数，而是从60家完整参考企业的“六维特征—公开指数”样本中重新学习代理公式。
