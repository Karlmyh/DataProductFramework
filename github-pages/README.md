# DataProductFramework

“数据产品安全衡量框架”的 GitHub Pages 静态版本。

## 当前页面

- `index.html`：五类数据产品、衡量流程与互动 Demo 首页。
- `privacy-lab.js`：3 个场景、15 个产品的切换、调用动画、攻击比较与结果聚合。
- `security_attacks/`：18 个三级产品类别的静态攻击说明页。

页面只使用 HTML、CSS 和原生 JavaScript，不依赖服务端运行时，可由 GitHub Pages 直接托管。

仓库此前下线的旧实验页面没有随本版本重新上线；首页中的“现有证据”链接指向下线前的 Git 历史记录。
