成员推断攻击案例

Case Setup

场景设定

这个页面固定展示 CASIA-FaceV5 real Chinese faces 上的 black-box label-only membership inference。每个 case 先用 ndata 张成员样本微调一个 target model，再用同样大小的 non-member 样本做攻击评估；黑盒 API 只返回 subject_group_a | subject_group_b 的 hard label。

输入数据2500
目标训练集256
目标测试集256
产品标签subject_cohort
query 个数64
数据源CASIA-FaceV5 real Chinese face photos prepared from the downloaded dataset.
微调模型torchvision/resnet50-imagenet1k_v2 backbone + trainable linear head
攻击协议single-target pretrained label-only oracle-threshold MIA
public reference 池1988 faces
target train / eval acc0.957 / 0.848
surrogate train / eval acc0.985 / 0.985

数据集样例

黑盒 API 模板

predict(face_image)
-> subject_group_a | subject_group_b

代表性 query

query #1
predict(augment(face_image, shift<=2, noise<=0.035, brightness_jitter<=0.10))
-> subject_group_a | subject_group_b

Repeated Perturbation Queries

The attacker only sees the hard label and repeatedly perturbs the same candidate face photo.

输出hard label
query pattern重复扰动

-> subject_group_a | subject_group_b
MethodReferenceRequired settingSummary
Label Stability
label_stability		ICML 2021 · Label-Only Membership Inference Attackshard label only + repeated perturbation queriesRepeatedly perturbs the same candidate image and uses hard-label stability as the membership score.
Sampling Attack
sampling_attack		AISec 2021 · Differential Privacy Defenses and Sampling Attacks for Membership Inferencehard label only + repeated perturbation queriesTreats repeated perturbation queries as a sampling process and scores how often the hard label survives.

Public-Reference Boundary Probes

The attacker still only gets the hard label, but can interpolate the candidate against public reference faces.

输出hard label
query pattern跨样本插值
public reference有
方法数2

对应 API 接口

predict((1 - alpha) * face_image + alpha * public_reference_face)
-> subject_group_a | subject_group_b
MethodReferenceRequired settingSummary
Transfer Attack
transfer_attack		CCS 2021 · Membership Leakage in Label-Only Exposureshard label only + public reference facesInterpolates the candidate toward public reference faces and transfers the resulting boundary gap into a membership score.
Boundary Attack
boundary_attack		CCS 2021 · Membership Leakage in Label-Only Exposureshard label only + public reference facesUses direct interpolation probes toward opposite-label public references to estimate how far the target lies from the decision boundary.

Fixed-Direction Boundary Probes
