单体断言核验
攻击页面

判断一个对象是否具有某项属性、满足某个条件或处于某种状态。

攻击面判定

核心交付

判断一个对象是否具有某项属性、满足某个条件或处于某种状态。

主要暴露

有限状态仍会泄露对象属性、名单命中与规则阈值；重复查询会把核验接口变成可枚举的判断预言机。

分类边界

只确认一个对象的一项属性或状态；若比较两个表征是否属于同一实体，归入 0102。

三级产品分支

  1. 010101 权威记录核验
  2. 010102 文档与数字凭证核验
  3. 010103 测试、测量与检验核验
  4. 010104 第三方声明与见证核验
  5. 010105 规则或模型推定核验

主要攻击

  1. 01敏感属性枚举
  2. 02名单与状态探测
  3. 03规则阈值推断
  4. 04硬标签成员推断
