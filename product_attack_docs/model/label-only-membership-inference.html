仅标签成员推断

适用产品

服务方式

硬标签预测接口。输入候选样本，只返回类别、通过、拒绝或相似的离散判断。

攻击对象

训练数据成员关系，即候选样本是否参与过模型训练、校准或微调。

攻击思路

扰动查询

围绕同一候选样本生成轻微扰动、插值或边界扫描样本，观察输出标签是否稳定。

成员分数

把标签翻转频率、近似边界距离和局部稳定性转换为成员分数，再与非成员候选比较。

间接性

接口没有输出训练集名单；成员关系来自多次 hard-label 响应的统计差异。

评估口径

指标

AUC、攻击准确率、TPR@10%FPR、不同查询预算下的稳定性。AUC 接近 0.5 时应写成弱分离或有限泄露。
