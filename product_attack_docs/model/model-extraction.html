模型抽取

适用产品

服务方式

可重复查询的预测 API，返回 hard label、score、rank 或其他模型输出。

攻击对象

目标模型的预测函数、局部决策边界或可替代部署能力。

攻击思路

查询样本

从公开数据、合成样本或业务允许的输入空间中构造查询样本，收集目标模型输出。

替代训练

用目标输出作为伪标签训练 surrogate model，并在保留集上比较 surrogate 与目标模型的一致性。

间接性

攻击者没有拿到真实权重，但可以通过输入输出行为复制一个功能相近的预测模型。

评估口径

指标

target agreement、surrogate accuracy、query budget、每类错误模式和置信度差异。评估时应明确是否只复制局部边界。
