模型类数据产品

服务方式

硬标签预测接口

接口只返回类别、通过或拒绝等离散结果。攻击者不能直接看到置信度，但可以通过重复查询观察边界稳定性。

评分或后验概率接口

接口返回概率、置信度、logit、loss 相关分数或排序信号。连续输出会放大候选样本之间的差异。

导出模型或参数

产品交付模型文件、权重、梯度相关信息或本地推理能力。攻击者可以离线构造成员分数或分析决策边界。

可重复查询预测服务

模型以 API 形式持续开放，允许在查询预算内批量提交公共样本或合成样本，适合评估模型抽取和局部复制风险。

攻击内容

仅标签成员推断

用 hard-label 响应的稳定性、边界距离或扰动结果判断候选样本是否属于训练集。打开页面

评分成员推断

用 posterior score、confidence、loss、margin 或 entropy 构造成员分数。打开页面

白盒成员推断

在模型参数或本地推理可见时，用 loss、margin 和梯度近似信号判断成员关系。打开页面

模型抽取

用公共输入批量查询目标模型，再用目标输出训练替代模型，复制预测函数或局部边界。打开页面

模型反演

利用分数、置信度或梯度优化输入，恢复类别原型、训练分布形态或局部敏感属性。打开页面

评估口径

指标统一尺度

模型类页面里的 AUC、TPR@固定 FPR、target agreement、fidelity 和反演恢复率，需要和其他攻击指标统一解释。打开页面
