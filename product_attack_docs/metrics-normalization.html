攻击指标与统一尺度

基本原则

保留原始指标

统一分数只用于横向比较。报告中仍应保留原始 AUC、TPR@FPR、balanced accuracy、重建率、误差、fidelity、query budget 和样本规模。

统一方向

所有归一化结果都写成 0 到 1 的风险分，0 表示没有超过基线的攻击收益，1 表示在该指标定义下接近完全成功。

先减基线

只把超过随机猜测、条件先验、公共数据先验或无查询基线的部分算作接口新增泄露。基线本来能推断出的部分，不应计入产品接口风险。

固定约束

不同攻击比较时必须同时写明查询预算、误报约束、样本规模、随机种子、可见输出和攻击者先验。没有这些约束，统一分数容易误导。

常用指标

推断类攻击

属性推断、成员推断、训练属性推断通常使用 AUC、balanced accuracy、attack accuracy、TPR@固定 FPR、相对条件先验提升和子群提升。类别不平衡时优先使用 AUC 或 balanced accuracy。

重建类攻击

数据库重构、差分重建、线性系统重建通常使用 exact reconstruction rate、字段恢复率、precision、recall、MAE/RMSE 降低比例和重建误差。只报告误差时要说明误差越低风险越高。

边界和阈值攻击

决策边界推断、排序和分段泄露通常使用阈值误差、边界距离误差、rank correlation、top-k overlap 和分段命中率。它们需要用误差降低或相关性提升来转换成风险分。

模型抽取

模型抽取使用 target agreement、fidelity、surrogate accuracy、transfer success 和 query budget。用于安全风险比较时，优先看 surrogate 与目标模型输出的一致率，而不是 surrogate 在公开测试集上的任务准确率。

模型反演

模型反演使用属性恢复率、原型可识别率、重建误差、目标类别置信度和人工或自动识别成功率。模型 confidence 只能作为诊断信号，不能单独等同于真实隐私泄露。

当前攻击页对应指标

核验类

属性推断用 balanced accuracy、相对先验提升和子群提升；成员推断用 AUC、TPR@固定 FPR 和 balanced accuracy；决策边界推断用阈值误差、边界距离误差和查询次数。

指标型

评分属性推断用 balanced accuracy 和 prior lift；评分成员推断用 AUC、TPR@固定 FPR 和分数分布分离度；置信度模型反演用恢复率、重建误差和相对先验提升；训练属性推断用 AUC、balanced accuracy 或分布检验 power；排序与分段泄露用 rank correlation、top-k overlap 和阈值误差。

数据库类

区间查询重建、差分重建和线性系统重建用 exact reconstruction rate、字段恢复率、precision/recall 与误差降低；背景知识属性披露用 balanced accuracy、条件先验提升和校准误差；查询组合风险用新增恢复率、最大单点风险和组合后的边际提升。

模型类

仅标签成员推断用 AUC、TPR@固定 FPR、attack accuracy 和 query budget；评分成员推断用 AUC、balanced accuracy、TPR@固定 FPR；白盒成员推断用 AUC、balanced accuracy、TPR@固定 FPR 和信号消融；模型抽取用 target agreement、fidelity、surrogate accuracy 和 query budget；模型反演用恢复成功率、原型可识别率、重建误差和目标置信度。

归一化公式

高值代表高风险的指标

使用 risk = clamp((value - baseline) / (max_value - baseline), 0, 1)。例如恢复率、fidelity、target agreement、balanced accuracy 和 attack success rate 都可以用这个形式。

低值代表高风险的误差指标

使用 risk = clamp((baseline_error - attack_error) / baseline_error, 0, 1)。例如重建误差、阈值误差、边界距离误差和属性估计误差。

AUC

二分类推断的随机基线是 0.5，使用 risk_auc = clamp((AUC - 0.5) / 0.5, 0, 1)。AUC 低于或等于 0.5 时，统一风险分记为 0。

Balanced accuracy

二分类 balanced accuracy 的随机基线也是 0.5，使用 risk_ba = clamp((BA - 0.5) / 0.5, 0, 1)。普通 accuracy 只有在类别均衡或已经减去多数类先验时才适合这样处理。

TPR@固定 FPR

当误报率固定为 f 时，使用 risk_low_fpr = clamp((TPR_at_f - f) / (1 - f), 0, 1)。这样可以避免把随机排序在同一误报率下的命中写成泄露。

模型抽取 fidelity

使用 risk_fidelity = clamp((agreement - baseline_agreement) / (1 - baseline_agreement), 0, 1)。baseline agreement 可以是多数类模型、随机标签模型或不查询目标模型的公开数据 surrogate。

重建率和恢复率

如果指标本身是 exact recovery rate、field recovery rate 或 identification success rate，且基线已经为 0，可以直接使用该比例。若存在公共先验恢复率，应先按高值公式减去先验。

汇总规则

先选主指标

成员和属性推断优先用 AUC 或低误报 TPR；重建攻击优先用 exact recovery 或误差降低；模型抽取优先用 target agreement；模型反演优先用恢复成功率或可识别率。

再报辅助指标

query budget、运行时间、样本规模、置信区间、不同 seed 的标准差和攻击者先验不并入主风险分，但必须作为解释条件同时报告。

多个指标不要随意平均

同一攻击有多个归一化指标时，默认使用预先指定的主指标作为该攻击分数。若要衡量最坏暴露面，可以取最大值；若要做综合评分，权重必须在评估前固定。

解释区间

0 到 0.1 可写作接近基线，0.1 到 0.3 可写作弱泄露，0.3 到 0.6 可写作中等泄露，0.6 到 0.8 可写作强泄露，0.8 到 1 可写作接近完全成功。区间只是展示口径，不替代业务风险判断。
