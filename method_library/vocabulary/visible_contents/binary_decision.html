额外检索线索

  • 2021 Label-Only Membership Inference Attacks (ICML)
  • 直接对应 hard-label / binary decision 场景，是当前 binary_decision 词项最关键的奠基锚点。
  • 2021 Membership Leakage in Label-Only Exposures (CCS)
  • 把离散判定输出明确推进到 decision-based / boundary-based MIA 场景，说明仅有 top-1 label 也可泄露成员信息。
  • 2024 Label-Only Membership Inference Attack Based on Model Explanation (Neural Processing Letters)
  • 说明只有离散输出时仍可通过边界/解释恢复成员信息，支持后续把 binary decision 与 label-only 风险绑定得更紧。
  • 2021 Differential Privacy Defenses and Sampling Attacks for Membership Inference (AISec)
  • 明确把“只看 predicted class label”作为攻击设置本身来研究，说明 binary decision 场景下重复查询会显著放大风险。
  • 2022 Black-Box Based Limited Query Membership Inference Attack (IEEE Access)
  • 补充了 query budget 受限下的成员推断路线，适合解释 binary decision 场景为什么不应被粗暴视为“信息太少所以安全”。
  • 2024 You Only Query Once: An Efficient Label-Only Membership Inference Attack (ICLR)
  • 进一步把 binary_decision 暴露下的攻击压缩到单次查询，直接打破“需要大量 probe 才危险”的乐观假设。
  • 2024 OSLO: One-Shot Label-Only Membership Inference Attacks (NeurIPS)
  • 把 one-shot 场景做成系统化成员推断，说明 binary_decision 已经足以支持独立、现实的攻击家族。
  • 2022 Evaluating Membership Inference Through Adversarial Robustness (The Computer Journal)
  • 这篇工作把 adversarial robustness 明确拿来作为成员推断信号来评估，是从“决策边界距离”走向“可比较风险测量”的一个重要桥梁。
  • 2025 Graph-Level Label-Only Membership Inference Attack Against Graph Neural Networks (Applied Sciences)
  • 虽然它不属于当前 API 主线，但它说明 binary_decision 风险已经扩展到图分类场景，label-only 家族并不是只在经典图像分类上成立。
