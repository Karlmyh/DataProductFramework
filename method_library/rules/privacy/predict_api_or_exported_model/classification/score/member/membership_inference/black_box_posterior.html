  • R_full_priority: oracle, literature_best, theoretical_ceiling
  • 聚合：
  • 同一 attack_family 取 max(E)
  • 同一 攻击对象 下多个 family 取 max(E)
  • 同一 score_domain 下多个对象取 max(E)
